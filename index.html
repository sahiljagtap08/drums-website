Infrastructure for computer-use training

More computer-use training
on less hardware.

Drums is building infrastructure to run more independent training attempts on the same machine. We're starting with macOS.

Talk to us Our approach ›
01 — The problem

Agents need practice. Computers are expensive.

Training an agent to use real software means thousands of attempts, each starting from a known state and isolated from the rest. Today that means a virtual machine per attempt, and memory and compute scale with the count.

02 — The approach

Share what's identical. Isolate what's different.

Most attempts begin from the same OS, the same apps, the same files. We're building an architecture where attempts share those common resources and only the changes each agent makes are kept separate.

03 — What we measure

More useful training per machine.

Concurrency, memory per attempt, attempts per hour, and correctness of isolation and reset, against conventional VMs. Target: 3–5× more concurrent attempts on the same hardware. A target, not a result yet. We'll publish numbers as we validate.
