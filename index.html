Drums Infrastructure for computer-use AI training

More computer-use training on less hardware.

Training AI agents to operate real software requires millions of attempts across browsers, desktop applications, and operating systems. Each attempt needs an independent computer environment, and running thousands of them at once gets expensive.

Drums is building infrastructure to run more independent training attempts on the same hardware. We're starting with macOS.

[Early research and development. We're working with researchers and engineers training computer-use agents.]

The problem

Teaching an agent to use a computer requires more than screenshots and examples. It needs to practice. An agent might attempt the same task thousands of times, making different decisions, hitting errors, and learning from the outcomes. Every attempt must start from a known state and stay independent of the others.

Today, researchers commonly use virtual machines and isolated desktop environments for this. These already support snapshots and shared disk images, but running many environments concurrently still consumes substantial memory and compute. As the number of attempts grows, the infrastructure gets increasingly expensive.

The approach

Most training attempts begin with nearly identical environments: the same operating system, the same applications, the same initial files. What differs is what the agent does next.

We're investigating an architecture that lets independent attempts reuse common operating-system and application resources while isolating the changes each agent makes. One underlying pool of resources, many independent training attempts, without sacrificing isolation or the behavior of real applications.

What we're measuring

We're evaluating Drums against conventional virtual-machine approaches on concurrency, memory per attempt, attempts completed per hour, and correctness of isolation and reset.

Our initial research target is 3–5× more concurrent training attempts on the same hardware. This is a target, not an achieved result. We'll publish measurements as we validate the architecture.
